Read before trusting this. These numbers use a resting stop-limit fill at the range edge (+0.25R "proactive"). If you instead tap the alert after the 1-min close, expect about +0.12R (still positive every year) — the alert can only fire once the break is confirmed, by which point price has moved. To capture the +0.25R you must place the order at the edge before the break (one arm-tap at 09:45). In-sample: discovered on this same 4-year data, so per-year consistency is the robustness proxy, not a true hold-out. The live dashboard shows realized forward performance — that is the number that counts. Not financial advice.
